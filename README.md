# Limited Yield

Monochrome fork of Infinite Yield. Built clean by shiftlock and zntrx.

## Load
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/lowkeymyself/Limited-Yield/main/source.lua"))()
```

## What changed
- Renamed to Limited Yield (title, credits, chat logs, notify strings, version check)
- Killed Discord branding (discord command, reference popup, plugins hint)
- Full monochrome palette (all accent colors removed)
- Auto-update now pulls from this repo
- Loader on teleport points here

## New commands
| Command | Action |
|---|---|
| `;soundlist` | Lists all Sound instances in workspace with names and IDs |
| `;playsound [id]` | Creates and plays a Sound with the given asset ID |
| `;stopsound` | Stops and removes all sounds created by playsound |
| `;freecamtp` | Teleports you to where your freecam is looking |
| `;konstant` | Loads the konstant script |
